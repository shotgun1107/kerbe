# CLI 설계 작업 상태

갱신: 2026-10-02 · 집 PC 인계 준비

## 목표와 완료 조건

확정 철학을 바탕으로 명령별 역할·입력·출력 사양을 사용자와 확정한다. GPT는 과거 기록·현재 구현 근거를 제공하고 사용자가 Claude와 정리한 확정 결론을 전달하면 정식 문서에 반영한다. 철학 1~7과 수집·동기화 역할·키 A안은 확정, report 사양과 제품 구현은 미완료다.

## 현재 상태와 실제 변경

- 작업 브랜치: docs/identifier-key-policy. 시작 HEAD/main은 `026a8a0e4cd6a0a7782f90f0848e641b33759a3e`. 이 인계는 A안 후속 문서 전송이다. main에 병합했다고 가정하지 않는다.
- D-069: 식별용 HMAC 키는 비공개 장부 내부, 제목 키는 별도 외부 보관. 기존 키 정책과 공통 규약의 한정 예외를 명시했다. 실제 키·장부·코드는 변경하지 않았다.
- 정본: [명령 설계](../../CLI_COMMAND_DESIGN.md), [철학](../../CLI_PHILOSOPHY.md), [결정](../../DECISIONS.md). 현재 실행 동작은 [CLI_REFERENCE](../../CLI_REFERENCE.md), 개발 규약은 [CONTRIBUTING](../../CONTRIBUTING.md).
- 이전 규약 정리와 Windows 테스트 수정은 PR #1로 main에 병합됐고 당시 작업 브랜치는 삭제됐다. 과거 커밋은 보존했다.

## 실행한 검사와 결과

- 이번 인계: 원격 main을 fetch해 위 SHA로 고정, 시작 HEAD와 같음 확인. 진행 중 Git 작업·stash·보조 worktree 없음. 변경은 문서만이며 제품 경로는 변경하지 않았다.
- 앞선 A안 문서 검사: 링크·UTF-8·공통 규약 원문 보존·diff 검사 통과. 이번 최종 전송 파일도 재검사한다.
- 과거 검증: 식별자/encoder/replay 24개 통과, 합성 키 차이 4종 확인. 전체 테스트는 Windows 경로 수정 후 182개 중 181 통과·Credential Manager 1 skip. main 026a8a0의 원격 Windows·Ubuntu CI도 성공했다. 이번 문서 인계에서 제품 테스트·빌드는 재실행하지 않는다.

## 미해결 문제와 남은 위험

- A안 이전 절차, 서로 다른 키로 시작한 로컬 기록 합류, 제목 암호화 방식, 장부 ID·파일 형식·허용 Git 경로는 미설계다.
- 같은 원본의 기기별 독립 수집 충돌, turn 없는 기록의 위치 변경 중복 가능성, 알려진 기록 자동 정정 미지원은 [OPEN_QUESTIONS](../../OPEN_QUESTIONS.md)에 남아 있다. report 자동 수집·현지 시간대는 현 코드에 미적용이다.
- 기존 로컬 인계 파일 2개는 미전달한다. 개인 장부·키·로그인·.venv도 Git 전송 대상이 아니다. 집 PC 실행환경은 미확인이다.

## 다음 행동과 필요한 사용자 결정

1. 집에서 실제 로컬 변경·HEAD를 확인하고 SYNC에 기록된 원격 작업 브랜치를 받아 이어간다. 과거 인계의 실행 지시를 새 승인으로 확대하지 않는다.
2. report 기본 화면부터 Claude와 논의한다. 기본 오늘·현지 자정, 자동 수집/sync, 불완전성 표시, 최신 정정 반영은 확정이다. 이를 다시 선택하지 않는다.
3. 아직 정하지 않은 것은 기본 행/열/정렬과 계정 한도 관측의 배치다. 몇 가지 예시 결과를 비교하되 정답을 먼저 정한 페르소나에 끼워 맞추지 않는다. 프로젝트별 토큰을 프로젝트별 실제 한도 소비로 표현하지 않는다.
4. 기본 화면 확정 후 대상·기간 선택 → 필터/집계/정렬/열 조합 → 내보내기를 논의한다. 기간의 세부 경계·저장 경로·형식·덮어쓰기 등은 미정이다. 새 결론 전 코드 구현은 하지 않는다.

Git 전달 커밋·받는 기기의 환경 확인 범위는 [SYNC](../../SYNC.md)에 남긴다.
