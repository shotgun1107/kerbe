갱신: 2026-10-02

## 목표와 완료 조건

확정 철학을 바탕으로 명령별 역할·입력·출력 사양을 사용자와 확정한다. GPT는 과거 기록·구현 근거를 제공하고, 사용자가 Claude와 정리한 결론을 전달하면 정식 문서에 반영한다. 철학 확정은 완료됐으나 명령 사양·제품 구현은 미완료다. 현재 규약 도입은 이 작업의 재개 경로를 정리하는 문서 작업이다.

## 현재 상태와 실제 변경

- 도입 시작 HEAD: `6e28a9609f695679f7c063e83090561b6f23dccb`. 최소 규약 도입 브랜치: `docs/development-guidelines`. 기존 main 이력 변경 없음.
- 시작 시 미커밋: CLI_DESIGN_REVIEW·ROADMAP 수정, CLI_COMMAND_DESIGN 미추적. 해당 설계 내용은 보존하고 AI 진행 안내만 이 기록으로 분리했다.
- CONTRIBUTING에 사용자 공통 규약 1~9와 Kerbe 적용 정보를 추가하고 AGENTS 진입점을 만들었다. README·PROCESS·CLI_REFERENCE·설계 검토 자료의 중복 규칙/진행 지시를 정리했다.
- SYNC는 과거 원본을 유지하고 최신 전달 상태와 이 기록의 링크를 추가했다. 루트 문서의 docs/ 일괄 이전은 하지 않았다.
- 규약 원문 위치: [CONTRIBUTING](../../CONTRIBUTING.md). 제품 근거: [철학](../../CLI_PHILOSOPHY.md), [명령 대조](../../CLI_COMMAND_DESIGN.md), [현재 동작](../../CLI_REFERENCE.md).

## 실행한 검사와 결과

- 저장소 정리 후속: 기존 Windows CI 실패를 짧은 임시 경로로 재현하고 기대 경로를 정규화했다(de30ea7). 전체 182개 중 181 통과·1 skip, 8.3 직접 재현 통과, 표준 격리 wheel 성공. no-build-isolation은 backend 부재로 실패했다. 새 원격 CI는 전달 후 확인한다.

- 명령 설계 1단계 후속 확인: 식별자/encoder/replay 기존 테스트 24개 통과, 합성 키 차이 실험 4종 통과. 키가 다르면 ID가 달라지고 혼합은 거절된다. 실제 키 접근 없음. 코드 변경 없음.

- 도입 전 지침·Git 상태·단일 worktree·CI/패키지 경로 의존성을 확인했다. upstream 비교 0/0은 로컬 추적 ref 기준이며 실제 원격을 조회하지 않았다.
- 도입 검증 완료: 문서 11개의 로컬 링크·UTF-8, 공통 규약 9절·짧은 진입점·작업 기록 1개, git diff --check 통과. 시작 전후 해시 비교에서 제품/고정 원본/로컬 전용 파일은 변경 없음. 과거 SYNC 본문은 원문 그대로 유지, HEAD도 동일하다.
- 최소 문서 도입 단계에서는 제품 테스트·빌드를 실행하지 않았다. 이후 사용자 위임으로 CI 테스트 수정과 위 회귀·wheel 검증을 수행했다. 실제 장부·계정 API·설치본 검증은 이번에도 수행하지 않았다.

- 앞선 코드 검토에서 관련 기존 테스트 63개 통과 및 임시 실험 성공을 확인했지만 이번 도입에서 재실행하지 않았다. 같은 원본의 두 기기 독립 수집은 충돌, turn ID 없는 기록의 위치 변경은 이중 계산 가능성을 확인했다. 전체 collect 경로·모든 장애에 대한 무결함 보장은 아님. 중요한 구현 위험과 미검증 범위는 OPEN_QUESTIONS의 지연 수집·재시도 항목에 보존했다.
